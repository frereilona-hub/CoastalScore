How AI should work

Designed for investor trust

01
Use evidence, not guesses

Base answers on the selected property's data, show the source and retrieval date, and label missing evidence.

02
Separate two types of risk

Climate exposure describes a hazard; financial impact depends on the building, insurance, mitigation and investment assumptions.

03
Explain the trade-off

Summarise upside, downside and the next checks an investor should complete—without making a guaranteed buy/no-buy decision.

To make this a real AI feature, the next step is to connect a model API securely through a backend and pass it verified property data. Never put a private API key in this HTML file.
Transparency by design

Methodology & data

Professional risk intelligence needs traceable sources, dates, confidence levels and clear limitations—not just a score.

01 / SOURCE

Document the evidence

Every metric should display the source organisation, dataset name, retrieval date, geographic resolution and direct source link.

02 / CONFIDENCE

Show what is known

Separate verified property data from neighbourhood proxies, model estimates, user inputs and missing information.

03 / DECISION

Translate risk into diligence

Connect exposure indicators to follow-up actions and financial scenarios without presenting correlation as a guarantee.
